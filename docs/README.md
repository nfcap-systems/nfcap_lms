# Docs

Reference material for the NFCAP LMS prototype. Code comments across `src/` and
`prisma/` link to these files by their repo-relative path (`docs/<folder>/<file>`).

## product/

| File | Purpose |
| --- | --- |
| `product/PRODUCT_CONTEXT.md` | Source of truth for product scope, roles, and feature decisions. |
| `product/NFCAP_SITE.md` | Notes on NFCAP's real (unfinished) marketing site — reference only. |

## design/

| File | Purpose |
| --- | --- |

| `design/NFCAP_DESIGN_TOKENS.md` | Brand palette/typography scraped from nfcap.org (partly superseded). |

| --- | --- |
