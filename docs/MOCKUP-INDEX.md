## ⚠️ Canonical data-table pattern — standard for every Admin list view going forward

**2026-11-20.** User decision: every table/list screen in the Admin dashboard (Learners, Cohorts,
Review Queue, Roles, WIOA Boards' list view, and any future one) must use **one exact pattern**,
copied from the clone's real `/dashboard/users` page
(`c:\Users\sthas\Projects\temp\next-shadcn-admin-dashboard\src\app\(main)\dashboard\users\`:
`users.tsx` + `users-table.tsx` + `users-columns.tsx`) — not approximated, not reinvented per board.
Built out in full on `temp_ss/adm03-wip.html` (verified: `adm03-wip-v1.jpg`) as the reference
implementation, replacing ADM03-Learners' old ad hoc toolbar (`.search`/`.chip` pill filters).
**Locked by the user 2026-11-20** — this is the final shape, ready to publish as the new
`ADM03-Learners` once the canvas is touched again.

**The pattern, top to bottom, all inside one bordered card (`.dtcard`):**
1. **Header** (`.dtcard-head`): title + one-line description on the left; on the right, a search
   box (with a `⌘K`-style kbd hint) plus secondary action buttons — copied 1:1 from the clone's
   Hide / Customize / Export / Add-entity button row (`.dtbtn`).
2. **Filter row** (`.dt-filters-row`): left-aligned group of labeled dropdown filters ("Label:
   Value ▾"), one more right-aligned — remapped per board to real columns (Learners: Pathway/
   Cohort/Status + Funding; Roles: Role/Status; WIOA Boards: Status), never invented filters that
   assume data we don't have.
3. **Selected-count + view-toggle row** (`.dt-selrow`): "N selected" on the left, the list/grid
   `.viewtoggle` pill (same control introduced for WIOA01) on the right — every list view gets
   this toggle, not just WIOA Boards.
4. **The table itself**: row-level avatar carries a small status dot (`.av-dot` — green/amber/gray
   for active/active-this-week/stale), copied from the clone's `AvatarBadge` last-active indicator;
   a two-line identity cell (name + email, or name + sub-label); right-aligned "…" kebab actions
   column, never a bare text link.
5. **Footer** (`.dt-footer`): rows-per-page select + "Page X of Y" on the left, a **full**
   prev/page-numbers/next pagination control on the right (`.pagination`) — not just the
   "Showing N of M" text the boards had before.

**Boards still on the old pattern, to retrofit when each is next touched** (not done now — this
was a reference-implementation pass on ADM03 only): `ADM13-Cohorts`, `ADM10-ReviewQueue`,
`ADM17-Roles` (already reskinned this session with a lighter version of this — toolbar + filters

`WIOA01-Boards` list view (same — has the view toggle and search but not Hide/Customize/Export or

**Before publishing:** all of `.dtcard*`, `.dtbtn`, `.dtsearch`, `.dt-filter*`, `.dt-selrow`,
